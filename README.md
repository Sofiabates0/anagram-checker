# Anagram Checker

A text utility for comparing letter arrangements.

## Features

- Text normalization
- Letter comparison
- Anagram detection

## How to Use

Enter two words or phrases and check the result.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
